Trackada est un programme qu'on lance dans le terminal.Il lit la liste des projets dans la track, verifie que chaque projet est bien rangé au bon endroit, que les fichiers sont presents, que git est installé et il affiche le pourcentage des projets corretcs.
Pour le lancer, ouvrir le terminal et aller dans le dossier du projet: cd ~ada-tech/bloc1.....
Lancer le programme avec node checktrack.js.
Exemple d'affichage:
C:\Users\sarah\ada-tech\bloc1\projets\trackada\track.json trackada
✅ fichiers present C:\Users\sarah\ada-tech\bloc1\projets
C:\Users\sarah\ada-tech\bloc1\projets\trackada\package.json trackada
❌ fichiers erreur C:\Users\sarah\ada-tech\bloc1\projets
C:\Users\sarah\ada-tech\bloc1\projets\trackada\README.md trackada
❌ fichiers erreur C:\Users\sarah\ada-tech\bloc1\projets
true adalgo
le dossier existe
